# Widget-container fixture extension — 011

CCST008 remains the serialized format. New captured roots are `8209CD08` and `8209DF48`; old supported owner/rectangle roots remain readable. The no-observed-counter flag is valid only for zero-draw owner/container roots and preserves an absent memory page rather than synthesizing data. `8209CE40` and `8209CE48` are accepted bounded runtime entry points for controls, not arbitrary serialized roots.

The first captured container is restored once. The original visibility setter/getter is used for hide/show; other menu/book roots remain snapshot-driven. The `startup` stem is a captured instant of the animated title/Press START screen, not the previous checkpoint's credit frame or a reproduced animation.

Raw capture files and original before/after states are the evidence. Expected draw records are comparison oracles, never fallback geometry. Root counts and mutation tests do not measure game-code coverage.
